# Dual-Quota Selection

For every frozen niche quota, deterministic largest remainder assigns the global role total. Structure-first selects ascending `d_struct`; hardness then selects descending frozen HGB40 among remaining candidates; ties use coordinate hash. There is no lineage/diversity penalty, threshold, reference quota, oracle CE, backfill across niches, or ratio search.

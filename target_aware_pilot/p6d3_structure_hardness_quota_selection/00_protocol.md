# P6-D3 Frozen Protocol

Three preregistered within-niche structure/hardness ratios are selected over the exact P6-D0 pools. Structure uses minimum squared P6-A Top5 reference cost; hardness uses frozen M4-conditioned HGB40. Structure-first, largest-remainder quotas, hash ties, lambda=.5 and all training/evaluation settings are immutable. No mutation, evolution, Concorde, HGB fit, ratio search or benchmark-driven selection is permitted.

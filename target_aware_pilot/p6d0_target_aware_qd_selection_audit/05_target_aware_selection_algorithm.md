# Target-Aware Selection Algorithm

For each replicate A is the exact original QD+HGB rule. Its realized niche counts normalized by 10k form the offline-equivalent `p_base`. For lambda=.5 or 1, ideal mass is `K*((1-lambda)*p_base + lambda*p_target)`. Integer capacity projection exactly minimizes squared L2 quota error subject to sum=10,000 and `0<=q_k<=available_k`: initialize clipped floors and repeatedly add the unit with smallest convex marginal cost, tie-breaking by niche id. B samples uniformly without replacement inside each lambda=.5 niche using the frozen replicate seed. C takes highest frozen HGB score; D takes highest hidden true CE and is diagnostic only. E applies HGB to lambda=1 quotas. No implicit backfill, true-CE repair, lineage rule, or benchmark tuning occurs. This quota mechanism is a target-aware offline adaptation; it is not byte-equivalent to the original survivor code.

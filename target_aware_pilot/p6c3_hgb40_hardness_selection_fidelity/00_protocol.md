# P6-C3 Frozen Protocol

This offline audit replays the formal C04 M4-conditioned five-seed HGB40 ensemble without fitting, calibration, mutation, Concorde, or BQ training. Raw predictions are `expm1(median(seed log1p predictions))`. P6-C1 thresholds, E0 decile quotas, target references, Top5 geometry, and candidate unions are immutable. If predicted-bin supply is insufficient, exact selection stops without threshold changes or backfill.
